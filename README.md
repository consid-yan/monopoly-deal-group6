## Installation and Running

### Requirements
- JDK 25 or later
- IntelliJ IDEA
- Maven

### Run locally
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Wait for Maven to finish importing dependencies.
4. Run `AppStart.java` from `src/main/java/ie/ucd/bdic/group6/app/` as the main entry point.

### Network mode
1. Start the server first.
2. Then start the client on each player machine.
3. Enter the server IP and port to join a room.


## Project Introduction

This project is a digital version of Monopoly Deal. It supports card-based gameplay, turn management, player asset tracking, action card resolution, and JavaFX-based user interaction.

We designed the project using a layered architecture with separate modules for core game logic, UI, and network communication.

The project focuses on implementing the core game rules, multiplayer synchronization, and a JavaFX-based user interface.

## Project Structure

- `core/`: core game rules and logic
- `ui/`: JavaFX views and interface components
- `controller/`: UI event handling and coordination
- `facade/`: unified entry point for game operations
- `network/`: client-server communication
